Known issues

Bugs and design inconsistencies found during a full review of the autograd subsystem (Matrix.hpp, Tensor.hpp, Operation.hpp, the overload files, and the 19 operations), current as of July 20, 2026. Check this page before relying on the affected APIs.

#FileSeverityDescription
1 Matrix.hpp — at(Matrix<bool>) critical The branch that constructs res in the nominal case never returns a value — undefined behavior. Called directly by IndexOperation::forward(), so Tensor::bool_index() is concretely affected. Fix before relying on boolean indexing. → Matrix reference
2 Matrix.hpp — mean() (no axis) latent bug this->sum() / (T)this->data.size — missing parentheses on size (a method, not a member). Shouldn't compile if instantiated; Tensor::mean(axis) always uses the correct axis-based overload instead. → Matrix reference
3 Matrix.hpp — pow(Matrix<T>, T) dead code Malformed call (single-argument std::pow, stray comma inside push_back). Shouldn't compile if instantiated — likely dead code.
4 Matrix::ln() vs. LogOperation::backward inconsistency ln() silently clamps input to ≥1e-9 on forward, but backward divides by raw t1 with no matching clamp — gradient potentially explosive near zero. → Operations reference
5 PowerOperation.hpp missing gradient Gradient with respect to the exponent t2 is never computed, though zero_grad() treats it as a normal participant. Harmless while the exponent stays a constant. → Operations reference
6 SumAxisOperation.hpp duplication Inverse-broadcast gradient logic is reimplemented independently of sumGradForBroadcast/Broadcast<T>::broadcastTo — risk of divergence if one is fixed without the other. → Operations reference
7 tensor_overloads.hpp API trap +=, -=, *=, /= on Tensor_t<T> do not mutate in place — different behavior than the same operators on std::vector<T> or Matrix<T>. → Overloads reference
8 Overload.hpp consistency Inconsistent error strategy: recoverable exceptions (Tensor::backward) vs. std::abort() (check_nan).
9 Overload.hpp consistency Inconsistent return types between order comparisons (std::vector<T>) and equality comparisons (std::vector<uint8_t>).
10 Overload.hpp silent Vector⊕vector operators silently truncate to min(|a|,|b|) on mismatched sizes — no error, no broadcasting. → Overloads reference
11 Matrix::stack limitation Does not generalize beyond 2D input matrices.
12 Operation.hpp minor Base class members t1, t2 are shadowed by derived classes — redundant, no functional effect.
13 General info avx2_pad is applied to matmul/dot's output buffer, but not to general constructor storage (that code path is commented out) — partial SIMD alignment. → Matrix reference
14 LlamaHyperParams::n_kv_heads verify Parsed from GGUF metadata but the current Llama<T> attention implementation does not perform grouped-query attention with a distinct KV head count — verify actual K/V weight shapes for your specific checkpoint before assuming full GQA compatibility. → ModelLoader reference
Where this list comes from Items 1–13 are drawn from an existing internal LaTeX code review of the autograd subsystem (dated July 20, 2026). Item 14 was observed independently while documenting ModelLoader. This is not an exhaustive audit of the full 92-file codebase — the Network/Profiler/DataLoader layers outside the autograd core have not had the same close review pass.
