GPT-2 text generation from a GGUF checkpoint

From GPT2.cpp — loads real GPT-2 small weights and generates a continuation for a prompt. Build with make gpt2 && ./bin/gpt2 (after downloading a checkpoint).

GPT2.cpp (excerpt)
#include "Modules/Transformer/GPT/GPT.hpp"
#include "ModelLoader/GPTLoader.hpp"

int main() {
    GPT2HyperParams hp {
        .vocab_size = 50257, .d_model = 768, .block_size = 1024,
        .n_layer = 12, .n_head = 12
    };

    GPTGGUFLoader<float> loader;
    GPT<float> model = loader.load_model("SLM/gpt2-small-f32.gguf", hp);
    GPT2Tokenizer tokenizer = loader.load_tokenizer();

    std::vector<int> token_ids = tokenizer.encode("The data type is int");
    std::vector<float> ctx_data(token_ids.begin(), token_ids.end());

    Tensor_t<float> context = make_tensor<float>(
        Matrix<float>(ctx_data, {1, ctx_data.size()}));

    auto out_tokens = model.generate(context, /*max_new_tokens=30, /*temperature=0.8f, /*top_k=30);

    std::cout << tokenizer.decode(out_tokens) << "\n";
}

Federated LoRA distillation — a client program

Assembled from the GPTLoRA and Federated Learning reference pages: a client that loads a frozen backbone, wraps it in a trainable LoRA adapter, and participates in a FedDistill round.

GPTGGUFLoader<float> loader;
GPT<float> pretrained = loader.load_model("SLM/gpt2-small-f32.gguf", hp);

GPTLoRA<float> student(hp.vocab_size, hp.d_model, hp.block_size,
                       hp.n_head, hp.n_layer, /*rank=8, /*alpha=16.0f);
student.load_backbone_from(pretrained);
student.load_head_from(pretrained);

Trainer<GPTLoRA<float>, float> trainer(student, nullptr, FEDDISTILL, /*lr=1e-4f);
// trainer's optimizer is built from student.lora_parameters() automatically —
// see federated.html#lora-detection

Client<float> net;
net.connect_to_server("127.0.0.1", 9000);

for (int round = 0; round < n_rounds; round++) {
    auto logits = trainer.compute_logits(probe_batch);
    net.sendLogits(logits.flatten_to_vector(), probe_batch.size());

    std::vector<float> consensus;
    net.receiveLogits(consensus, probe_batch.size());

    trainer.distill_logits(probe_batch, consensus);
}

Running the built-in test suite

make tests

basic_tests.cpp cross-checks Matrix<T> arithmetic, matmul, transpose, and reductions against known NumPy outputs, printing [PASS]/[FAIL] per case — the fastest way to confirm your OpenBLAS link and build flags are correct after making changes.
