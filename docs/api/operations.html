Operations catalogue

Every differentiable primitive in TensorF inherits from the abstract Operation<T> base and implements forward() plus backward(Matrix<T> grad). 19 concrete operations exist. All arithmetic below uses ⊙ for elementwise product.

Operation<T> base class Holds the input tensor(s) (t1, sometimes t2) and provides reset_graph(), which every subclass implements identically: call reset_graph() on inputs, then null its own reference (see memory management). Note: concrete subclasses shadow the base's t1/t2 members with their own — redundant but functionally harmless. See Known Issues #12.

Arithmetic

AddOperation — t1 + t2

Backward: the incoming gradient is redistributed identically to both inputs, reduced through sumGradForBroadcast.

SubtractOperation — t1 − t2

Backward: ∂L/∂t1 = grad, ∂L/∂t2 = −grad, both reduced via sumGradForBroadcast.

MultiplyOperation — t1 ⊙ t2

Backward (product rule): ∂L/∂t1 = grad ⊙ t2, ∂L/∂t2 = grad ⊙ t1.

DivisionOperation — t1 / t2

Backward: ∂L/∂t1 = grad / t2, ∂L/∂t2 = −grad · t1 / t2².

PowerOperation — t1t2 incomplete grad

Backward: ∂L/∂t1 = grad · t2 · t1t2−1.

The gradient with respect to the exponent t2 is never computed. Harmless while the exponent is a constant (the common case); breaks silently if you ever need t2 to be learnable. See Known Issues #5.

Elementwise functions

ExponentOperation — et1

Saves the forward output; backward: ∂L/∂t1 = grad ⊙ et1.

LogOperation — ln(t1) no clamp

Backward: ∂L/∂t1 = grad / t1. No protection against t1 ≤ 0 at the operation level — inconsistent with Matrix::ln()'s silent 1e-9 clamp on forward. See Known Issues #4.

Activations

ReluOperation

Backward: grad ⊙ (t1 > 0).

SigmoidOperation

Backward: grad ⊙ σ(x) ⊙ (1 − σ(x)), reusing the saved forward output.

SoftmaxOperation stabilized

Numerically stabilized forward (subtracts the per-row max before exponentiating). Applied along the last dimension, generalized to ND tensors.

Backward: the analytic Jacobian-vector product Sij(Gij − Σk GikSik), avoiding materializing the full N×C×C Jacobian.

Linear algebra

DotOperation

Backward: ∂L/∂t1 = grad · t2⊤, ∂L/∂t2 = t1⊤ · grad — without sumGradForBroadcast (exact shapes are assumed).

MatmulOperation batched

Backward: transposes only the last two dimensions when 3D ({0,2,1}), then reduces via sumGradForBroadcast. Consistent with the batched Matrix::matmul forward — see Architecture → matmul.

Shape manipulation

ReshapeOperation

Forward saves orig_shape. Backward: reshapes the gradient back to that original shape.

TransposeOperation

Three forward() overloads: no-argument, initializer_list<size_t>, or shape_t permutation, memorized in inperm. Backward: applies the inverse permutation to the gradient.

ConcatOperation variable arity

The only operation taking a std::vector<Tensor_t<T>>. Backward: splits the gradient (slice_axis) according to memorized split_sizes.

Lookup & indexing

EmbeddingOperation scatter-add

Backward: scatter-add accumulation — repeated indices sum their gradients correctly.

IndexOperation bug

Forward calls t1->val.at(mask) — directly inherits the missing-return bug in Matrix::at(Matrix<bool>). See Known Issues #1.

Reductions

SumOperation — full reduction to scalar

Backward: grad.data[0] * ones(shape) — the scalar gradient is broadcast uniformly back over the original shape.

SumAxisOperation duplicated logic

Forward reduces axis but keeps it at size 1 ({N,1}) to allow natural downstream broadcasting. Backward: reconstructs the full gradient via tiling/repetition — logic equivalent to an inverse broadcast, but manually reimplemented separately from sumGradForBroadcast/Broadcast<T>::broadcastTo. Risk of divergence if one is fixed without the other. See Known Issues #6.
