Modules — neural network layers

Every trainable layer subclasses Module<T>, which handles recursive parameter collection, gradient zeroing, and checkpoint save/load. Layers compose via register_module.

Module<T> — base class

template <typename T>
class Module {
    protected:
        std::vector<Tensor_t<T>> params;
        std::vector<Module<T>*>   submodules;
        Serializer<T>             Ser;

    public:
        void register_parameter(Tensor_t<T> p);
        void register_module(Module<T>* m);
        std::vector<Tensor_t<T>> parameters() const;  // recursive
        void zero_grad();                              // recursive
        void save(std::string path);
        void load(std::string path);
};

parameters() recursively concatenates this module's own registered parameters with every submodule's parameters() — this is what lets Optimizer<T> and Trainer<Model,T> collect an entire model's weights with a single call at the top level, regardless of nesting depth (GPT → Block → MultiHeadAttention → Head → Linear).

save()/load() format Delegates to Serializer<T>, which writes a custom binary format (magic bytes "TNSF", version, tensor count, then per-tensor rank/dims/data). load() throws if the loaded tensor count doesn't match parameters().size() — the checkpoint's architecture must match exactly. See DataLoader → Serializer.

Linear<T>

Linear(size_t out_features, size_t in_features, bool bias=true)

Weight shape {out_features, in_features}, Glorot-uniform initialized (limit = sqrt(6/(in+out))). Forward computes x->matmul(weight->transpose()) + bias when bias is enabled, else without the addition. Bias, when present, is zero-initialized and shape {out_features}.

LoRALinear<T>

LoRALinear(size_t out, size_t in, size_t rank, T alpha)

Low-Rank Adaptation layer: a frozen weight {in,out} (zero-initialized — meant to be loaded from a pretrained checkpoint, never trained directly, and not registered as a parameter) plus a trainable low-rank pair A {in,rank} (random-normal) and B {rank,out} (zero-initialized, so the adapter starts as a mathematical no-op).

Forward: base = x->matmul(weight); lora = x->matmul(A)->matmul(B); returns base + scale * lora where scale = alpha / rank.

Only A and B are registered as parameters — this is the mechanism the federated LoRA-distillation setup relies on to train a tiny adapter on a frozen backbone.

LayerNorm<T>

LayerNorm(shape_t normalized_shape, T eps=1e-5, T tol=1e-9)

Learnable gamma (ones-initialized) and beta (zeros-initialized), both shaped normalized_shape. Normalizes over the last axis — standard for transformer layer norm.

forward
mu    = mean(x, axis=-1)                // {..., 1}
sigma = sqrt(var(x, axis=-1) + eps)     // {..., 1}
xhat  = (x - mu) / sigma                // same shape as x
y     = gamma * xhat + beta

RMSNorm<T>

RMSNorm(shape_t normalized_shape, T eps=1e-5)

Used by the Llama family instead of LayerNorm. Skips mean-centring entirely and has no beta/bias parameter — only a learnable gamma scale.

forward
rms = sqrt( mean(x², axis=-1) + eps )
out = gamma * (x / rms)

Embedding<T>

Embedding(size_t vocab_size, size_t input_dim)

Glorot-uniform table of shape {vocab_size, input_dim}. Forward is a table lookup via Tensor::embed(indices), backed by EmbeddingOperation (scatter-add backward).

PositionalEncoding<T> / RotationalPositionalEncoding<T>

ClassTypeNotes
PositionalEncodingLearnableA Glorot-uniform weight table {max_sequence_length, input_dim}, looked up the same way as Embedding. Used by the plain GPT model.
RotationalPositionalEncoding (RoPE)Non-learnable, computedBuilds sin/cos position encodings via Matrix<T>::sin/cos over a frequency table, then interleaves and reshapes. Applied inside each attention Head, not at the embedding stage — see Llama internals.

FeedForward<T>

FeedForward(size_t in_features, size_t hidden, size_t out_features)

Two Linear layers with a ReLU in between: l2(relu(l1(x))). Note this is the Modules/FeedForward.hpp version; the Modules/Transformer/GPT/FeedForward.hpp variant used inside GPT blocks is functionally the same shape but uses GeLU instead of ReLU (see Transformers).

Relu<T> / Softmax<T>

Thin Module<T> wrappers around Tensor::relu() / Tensor::softmax() — useful for composing inside a NeuralLayer pipeline.

NeuralLayer<T>

NeuralLayer(std::initializer_list<Module<T>*> modules)

A simple sequential container: registers every module passed in, and forward(x) pipes x through each in order. Analogous to PyTorch's nn.Sequential.

Linear<float> l1(64, 32), l2(10, 64);
Relu<float> act;
NeuralLayer<float> net({&l1, &act, &l2});
Tensor_t<float> out = net.forward(x);

Optimizer<T>

Optimizer(std::vector<Tensor_t<T>> params, T lr, Optimizer_t mode)

Optimizer_t is one of SGD, ADAM, ADAMw. Extra constructor overloads let you override beta1, beta2, eps, and (for AdamW) the weight-decay lambda.

MethodBehavior
step()Always calls clip_grad_norm(1.0) first, then dispatches to the configured update rule.
zero_grad()Zeros every managed parameter's gradient.
clip_grad_norm(max_norm)Global L2 norm clipping across all parameters, BLAS-accelerated for float/double.

All three update rules (sgd, Adam, AdamW) use cblas_saxpy/cblas_sscal/cblas_daxpy/cblas_dscal for float/double, falling back to elementwise Matrix<T> arithmetic otherwise. AdamW applies decoupled weight decay (p *= (1 - lr*lambda)) before the Adam moment update — distinct from L2 regularization added to the gradient.
