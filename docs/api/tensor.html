Tensor<T>

The autograd graph node. Wraps a value, a gradient, and a pointer to the operation that produced it. Always used through Tensor_t<T> = std::shared_ptr<Tensor<T>>, never as a bare value.

Members

class Tensor : public std::enable_shared_from_this<Tensor<T>>
{
    Matrix<T> val;              // tensor value
    Matrix<T> grad;             // accumulated gradient
    shape_t shape;
    size_t ndims;
    Operation_t<T> backOp = nullptr;  // producing operation, or null for a leaf
    bool requires_grad = true;
};

Construction

Never construct a raw Tensor<T> — use the make_tensor<T>(...) family from tensor_overloads.hpp, which returns a properly-managed Tensor_t<T>. Overloads accept: nothing, a constant, a std::vector<T>, nested 1D/2D/3D initializer lists, a pointer/reference to Matrix<T>, or another Tensor_t<T> — each with a variant that also attaches an Operation_t<T>.

backward()

backward(Matrix<T> ingrad)
  1. Accumulates ingrad into this->grad (adds to any existing value — required when a tensor feeds multiple downstream ops, e.g. residual connections in a transformer block).
  2. Checks Matrix<T>::hasNaN(grad); throws if found.
  3. Calls backOp->backward(ingrad) if backOp is non-null, which computes local gradients and recurses into its own inputs' backward().

An overload backward(Tensor_t<T> ingrad) unwraps the tensor's val and forwards to the above.

Graph lifecycle

MethodEffect
zero_grad()Resets grad to zero. Graph structure stays intact and reusable.
reset_graph()Breaks the Tensor↔Operation shared_ptr cycle by nulling backOp, propagated recursively into inputs. Call this after every training iteration or the graph leaks — see Architecture → memory management.

Typical usage

Tensor_t<float> x = make_tensor<float>(Matrix<float>::randn({4, 8}));
Tensor_t<float> w = make_tensor<float>(Matrix<float>::randn({8, 16}));

Tensor_t<float> y = x->matmul(w)->relu()->sum();
y->backward(make_tensor<float>((float)1.0));

// x->grad and w->grad now hold dL/dx, dL/dw
y->reset_graph();
