Types

Core aliases used across every header, plus TensorF's two software floating-point types used for quantized checkpoints.

Core aliases

using shape_t = std::vector<size_t>;

template <typename T>
using Operation_t = std::shared_ptr<Operation<T>>;

template <typename T>
using Tensor_t = std::shared_ptr<Tensor<T>>;

Every shape in the codebase (tensor shapes, layer normalized_shape, etc.) is a shape_t. Every graph node is passed around as a Tensor_t<T> — raw Tensor<T> values are never handled directly by user code.

Fixed-width integer aliases

int8unsigned char
int16unsigned short int
int32unsigned int
int64unsigned long long int

Float aliases

float16, float32, float64 map to compiler _FloatXX extended types where available, falling back to uint16_t (storage-only, for float16), float, and double respectively.

FP8<E,M> — 8-bit software float

A single-byte struct storing sign + E exponent bits + M mantissa bits (E + M + 1 == 8, enforced with static_assert). Arithmetic operators decode both operands to float, compute, and re-encode — this is a storage format, not an accelerated compute type.

AliasLayoutUse case
fp8_e3m43 exponent, 4 mantissa bitsMore precision, less range
fp8_e4m34 exponent, 3 mantissa bitsThe common ML default (matches NVIDIA's E4M3)
fp8_e5m25 exponent, 2 mantissa bitsMore range, less precision

FP4<E,M> — 4-bit software float

AliasLayout
fp4_e2m12 exponent, 1 mantissa bit
fp4_e1m21 exponent, 2 mantissa bits

Note: an FP4 value is still a full byte-aligned struct in memory — real 4-bit packing (two codes per byte) only happens on disk, in Quantizer.hpp's save/load path. See DataLoader → Quantizer.

Type traits

template<typename T> struct is_fp8 : std::false_type {};
template<int E, int M> struct is_fp8<FP8<E,M>> : std::true_type {};

template<typename T> struct is_fp4 : std::false_type {};
template<unsigned short E, unsigned short M> struct is_fp4<FP4<E,M>> : std::true_type {};

Used throughout the codebase's if constexpr branches (e.g. Optimizer<T>::sgd(), Matrix<T>::dot()) to select the OpenBLAS-backed path for float/double versus a naive fallback loop for everything else, including fp8/fp4.

Forward declarations

types.hpp forward-declares Tensor<T>, Operation<T>, Module<T>, GGUFLoader<T>, GPTGGUFLoader<T>, and LlamaGGUFLoader<T> — this is what lets nearly every header in the project include types.hpp without a circular-include problem, since the aliases above only need the forward declaration, not the full class body.
