Checkpointing (federated server)
How TensorF checkpoints

The federated server binary checkpoints the global model on its own schedule — there is no gateway endpoint to trigger a save mid-run, only startup flags. Set these when you launch a server job:

--save-pathcheckpoints/global/model.tnsf (default)
--load-pathresume the global model from a checkpoint
--save-everysave every N FedAvg rounds, 0 = never (default 1)
--quantizealso save a compressed checkpoint: none | fp8 | fp4

The gateway is stateless across restarts — job history and logs live in memory only. A running server survives a gateway restart as an orphaned process; use Free / kill below (SIGTERM) to reclaim its memory.
